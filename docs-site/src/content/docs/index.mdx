## See it work in one command

```bash
simwork demo
# SimWork eval report — run: langgraph-demo-1 (seed 7)
#   tool_correctness: 1.00 (threshold 1.00) PASS
#   task_completion: 1.00 (threshold 1.00) PASS
# Overall: PASS
```

The demo is a small LangGraph agent that asks about a ticket, calls one LLM and one world API — both mocked — records the run as a trace, and gates it. Nothing real is ever called.

## Built for thousands of runs

SimWork's first use case is pre-launch testing on a near-zero budget: thousands of simulated runs before launch, to know how good the app will be in the real world. `simwork scale` repeats the demo 1,000 times against shared mocks — 1000/1000 passed, one trace hash, 42.6s, $0.

SimWork is open source (MIT). It simulates AI apps — it does not claim a simulated run proves real-world performance. Read the [design decisions](/reference/decisions/) for the honest limits.
